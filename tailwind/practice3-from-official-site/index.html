Arbitrary groups: i.e custom group ( works with parent-child relation)

  • Normally: Tailwind has predefined conditions like group-hover, group-focus .
  • Custom Selector (group-[...]): You can create your own condition by specifying a class like is-active in the parent. If the parent has this class, the child can react to it.
  • It gives you more control over your styles by allowing you to define custom conditions.
  • You’re not limited to built-in states like hover or focus.

Arbitrary modifier: i.e custom modifier, group-[modifier] (It helps in creating more complex and targeted rules.)

  • In Tailwind CSS, arbitrary modifiers and arbitrary group allow you to use custom values that Tailwind doesn't natively support.
  • you can pass any value you need between square brackets group-[css property or custom class] for properties like colors, spacing, typography, etc.
  • This makes your Tailwind setup much more flexible because you can define values that are not available by default without needing to modify your Tailwind configuration.
  • When using an arbitrary modifier or arbitrary group , you can provide a custom value inside square brackets, and Tailwind will interpret it as a valid utility class.
